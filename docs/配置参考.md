# 配置项参考

> 从主页搬出来的完整配置表（含默认值与取值范围）。返回 [项目主页](../README.md)。


完整模板见 [`config.example.json`](../config.example.json)。常用的几个：

> 改完之后跑一次 **`run.bat --show-config`**：它把每个选项的**生效值和来源**打印出来（`[文件]` / `[默认]` / `[环境]`），并点名 `DEFAULTS` 里没有的键 —— 拼错的键和你写对了但被 BOM 毁掉的整份配置，现象都是「改了没反应」。

> 某一项**类型写错**（`"variants": "four"`、`"max_candidates": 0`、`"dict_cache": 5`、`"bg": 5`、`"default_language": "jp"`）不会让程序崩掉、也不会悄悄坏掉：`load()` 会把那一项退回默认值，并在启动时打一句人话 —— `translate.variants 应该是整数（1~8），现在是 "four" —— 用默认值 4`、`pinyin.dict_cache 应该是缓存文件路径（一段非空文字），现在是 5 —— 用默认值 "pinyin_index.pkl"`。以前前两者会让 `--check` 一起崩在 traceback 里或候选窗一个候选都不画，后两者会直接崩在启动那一刻（拼路径的 `TypeError`、建控件的 `TclError`）。 同样地，`config.json` 里**拼错的键**（把 `font_size` 写成 `font_szie`、把 `hotkeys` 写成 `hotkey`）不会报错也不会生效 —— `load()` 启动时也会点名；`_` 开头的键/段当注释，不唠叨。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `api.model` | `deepseek-chat` | 翻译用的模型 |
| `api.api_key` | `""` | 留空则自动退回离线 mock 引擎 |
| `api.provider` | `deepseek` | 写 `mock` 强制走离线词表（没网 / 不想花钱时用）；写 `deepseek` 或留空则按有没有 key 自动选 |
| `translate.debounce_ms` | `250` | 停止输入多久之后才发翻译请求 |
| `translate.variants` | `4` | 译文行最多显示几条不同译法 |
| `translate.enabled` | `true` | 关掉就变成纯拼音输入法，不联网 |
| `pinyin.max_candidates` | `7` | 中文行最多显示几个候选 |
| `pinyin.min_freq` | `20` | 词频低于此值的词不进索引（调小会显著增大索引） |
| `output.default_language` | `zh` | 启动时默认高亮哪一行 |
| `output.start_enabled` | `true` | `false` = 起来后先挂起，按 `Ctrl+Alt+Z` 才接管 |
| `output.tray` | `true` | 是否显示托盘图标 |
| `output.log_file` | `translate-ime.log` | 后台模式的日志文件名（超过 2 MB 轮转成 `.1`） |
| `hotkeys.toggle_direct` | `""` | 绑一个组合键切「拼音 / 英文直通」；留空就只用单击 `Shift` |
| `hotkeys.<动作名>` | — | 合法动作名只有 `compose` / `quit` / `toggle_default` / `toggle_direct` / `toggle_enabled`；写错的名字会被忽略并在控制台 / 日志里点名，不会变成「按了没反应」。**组合键必须带修饰键**（`ctrl` / `alt` / `win` 至少一个），F1–F12 这类打字时不碰的单键例外：像 `"quit": "q"` 这种打字键会被直接拒绝注册（`--check` 判 FAIL、日志点名），否则打字打到它就会触发 —— 见踩坑第 72 条 |
| `input.shift_tap_ms` | `600` | 按下 Shift 后多久内松手算「单击」（超时按正常按住 Shift 处理）。第 20 轮从 300 放宽到 600：从容地「按一下去切模式」常常超过 300ms，那会变成什么都不发生。**设成 0 等于关掉 Shift 单击**（时间窗为零时永远不会触发，`--check` 会提醒） |
| `input.toast_ms` | `1600` | 候选窗上的短提示停留多久 |
| `overlay.*` | — | 配色、字号、宽度、透明度、候选窗与光标的垂直偏移 |
